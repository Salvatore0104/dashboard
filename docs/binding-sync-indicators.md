# 人员绑定提示与组织同步指示器

## 显示范围

- 仅后台人员卡片显示“已绑定／未绑定”。绑定需有稳定平台用户 ID，状态为 confirmed 或 auto_matched。
- 前台和 TV 不显示人员绑定标签。
- 前台“项目排期”旁显示 wowidea 组织核对状态，原四小时指示器明确标为请假同步。

## 核对规则

GET /api/project-sync/overview 只读查询平台组织树和用户，比较项目组织名称、执行项目组父节点、当前有效成员及已删除项目残留组织。数据缺失、接口失败、未启用真实同步、存在差异时不显示绿色对号。

前台每分钟重新核对，刷新和看板数据更新时也重新核对。提示的核对时间可悬停查看。只有组织状态一致时显示绿色对号；这不代表自动调度已开启。

下一次同步时间来自实际运行的项目调度线程；线程关闭时返回空值并显示“自动同步未开启 · 下次未安排”。不会把请假同步倒计时用于项目组织同步。项目调度默认关闭的设置未变。
